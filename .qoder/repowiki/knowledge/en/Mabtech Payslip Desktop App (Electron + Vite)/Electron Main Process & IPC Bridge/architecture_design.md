Single-file Electron main process (`index.ts`, compiled to `index.js`) with a flat `index.d.ts` stub. On `app.whenReady()` it registers an `electronApp.setAppUserModelId('com.mabtech.payslip')` identity, wires `optimizer.watchWindowShortcuts`, then mounts all IPC channels via `ipcMain.handle`. The module owns three internal concerns: (1) persistent JSON store under `app.getPath('userData')/data/database.json` with atomic write via `.tmp` + `renameSync`; (2) HTML-to-PDF rendering through a hidden offscreen `BrowserWindow` using `webContents.printToPDF`; (3) filesystem/dialog operations (open/save, folder picker, binary read, bulk export). The renderer is loaded from `../renderer/index.html` in production or `ELECTRON_RENDERER_URL` in dev, with preload at `../preload/index.js`. External URL opening is funneled through `shell.openExternal` and intercepted via `setWindowOpenHandler`. Dependency direction is one-way: this module calls Electron APIs, `@electron-toolkit/utils`, Node `fs/path/shell/dialog`, and never imports renderer code.
