The `electron.vite.config.ts` orchestrates three processes: the `main` entry owns the BrowserWindow and exposes IPC handlers for DB/file/PDF/backup operations; the `preload` script publishes a typed API surface over `contextBridge`/`ipcRenderer`; the `renderer` is a React SPA built with Vite+React. Cross-process communication flows exclusively through the preload bridge — the renderer never calls Node APIs directly. The renderer's UI composes a sheet table, an inline `AdvanceEditor` modal for bank-advance/cash-advance/bank-salary fields, settings, and HTML preview around a single persisted Db state owned by the main process. The main process persists all state to local JSON, which the renderer reads/writes through the preload bridge. The renderer's payslip output follows a fixed-template contract documented in README.md: every Salary Details row and every Earnings & Deductions row prints even when zero, with ESI/PF showing 'Not Eligible' instead of `0.00` when absent or `NOT ELIGIBLE`. Build output lands under `out/` and is packaged by `electron-builder` into NSIS installers under `release/`.
