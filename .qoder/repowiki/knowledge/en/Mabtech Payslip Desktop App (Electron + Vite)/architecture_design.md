Three Electron processes are orchestrated by `electron-vite` via `electron.vite.config.ts`: the `main` entry (`out/main/index.js`, declared in `package.json`) owns the BrowserWindow and exposes IPC handlers for DB/file/PDF/backup operations; the `preload` script runs in each renderer's isolated context and publishes a typed API surface over `contextBridge`/`ipcRenderer`; the `renderer` is a React SPA built with Vite+React. Cross-process communication flows exclusively through the preload bridge — the renderer never calls Node APIs directly. Build output lands under `out/` and is packaged by `electron-builder` into NSIS installers under `release/`.
