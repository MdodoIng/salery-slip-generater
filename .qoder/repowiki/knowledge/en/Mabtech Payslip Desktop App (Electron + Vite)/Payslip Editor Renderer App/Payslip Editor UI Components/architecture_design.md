Three independent presentational React components live side-by-side under `src/renderer/src/components/`, each shipped as a triple of `.tsx` (source), `.js` (compiled output), and `.d.ts` (type declaration) so the parent app can import either flavor. `SheetTable` is a stateless data grid driven by props (`rows`, `selected`, `onSelect`, `onChange`, `onDelete`, `onPdf`, `onDocx`) and uses shared types (`SalaryRow`, `grossOf`) from `../types`. `SettingsModal` is a controlled dialog backed by local `useState<Settings>` state, exposing `onSave`/`onClose` callbacks plus `onOpenDataFolder` for IPC into the Electron main process. `Preview` renders an `<iframe srcDoc>` scaled to fit an A4 page (794×1123 px at 96 dpi) using a `ResizeObserver`-driven scale factor. All three components are pure function components with no internal state management beyond their own props/local state — application state lives in the parent renderer, keeping these components reusable and testable.
