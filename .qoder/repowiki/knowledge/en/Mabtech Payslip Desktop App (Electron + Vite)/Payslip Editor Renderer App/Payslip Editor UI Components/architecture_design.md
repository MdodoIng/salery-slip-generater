Four presentational React components live side-by-side under `src/renderer/src/components/`, each shipped as `.tsx` / `.js` / `.d.ts`. `SheetTable` is the entry grid driven by props (`rows`, `selected`, `onSelect`, `onChange`, `onDelete`, `onPdf`, `onDocx`, `onEditAdvances`); for the three dated-advance fields (`bankAdvance`, `cashAdvance`, `bankSalary`) it renders an inline number input plus a ≡ list button whose click is delegated to the parent via `onEditAdvances(i, field)`. `AdvanceEditor` is a new controlled modal that owns local state of `AdvanceEntry[]` rows (date + amount), computes the summed total via `advanceItemsTotal`, and returns either the edited array or undefined entries through its `onSave` callback. `SettingsModal` remains a controlled dialog with local `useState<Settings>` and IPC delegation via `onOpenDataFolder`. `Preview` renders an `<iframe srcDoc>` scaled to fit an A4 page (794×1123 px at 96 dpi) using a `ResizeObserver`-driven scale factor. All four components are pure function components — application state and IPC live in the parent renderer, keeping them reusable and testable.
